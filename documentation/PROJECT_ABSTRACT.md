# PROJECT ABSTRACT
**Project Title:** MultiMart: An All-In-One Unified Multi-Model E-Commerce Marketplace  
**Domain:** Web Engineering, Distributed Systems, Database Architecture & Cybersecurity  
**Degree:** Bachelor of Technology (B.Tech) in Computer Science & Engineering / Data Science  

---

### Abstract
Contemporary electronic commerce architectures are largely fragmented into specialized domains: retail shopping portals cater strictly to consumers (B2C), enterprise supply procurement systems focus on business-to-business wholesaling (B2B), classified ad portals support peer-to-peer pre-owned transactions (C2C), and independent freelancing networks facilitate skill contracting (C2B). This architectural bifurcation results in duplicated authentication silos, disparate payment infrastructures, high administrative overhead, and inefficient cross-model user mobility.

**MultiMart** resolves this systemic fragmentation by pioneering an integrated multi-vendor, multi-model e-commerce platform that concurrently orchestrates all four foundational commerce paradigms on a single normalized relational database schema (Third Normal Form, 3NF across 30 tables) and unified role-based authorization framework:

1. **Business-to-Consumer (B2C):** Complete online retail shopping incorporating full-text catalog indexing, live asynchronous query suggestions, inventory reservation, dynamic coupon valuation algorithms, and order tracking.
2. **Business-to-Business (B2B):** Industrial and wholesale supply chain operations featuring Minimum Order Quantity (MOQ) enforcement, tiered volume pricing matrices, formal Request for Quotation (RFQ) negotiation, and GST-compliant tax invoicing.
3. **Consumer-to-Consumer (C2C):** Peer-to-peer pre-owned trading system supporting condition-based item grading, localized geodata tags, community moderation reporting, and asynchronous buyer-seller messaging.
4. **Consumer-to-Business (C2B):** Dedicated technical services marketplace enabling independent professionals (Data Science, Machine Learning, Full-Stack Development) to publish multi-tier contract packages (Basic, Standard, Premium) and execute milestone-based contracts with enterprise clients.

The system is developed using modern web engineering principles: PHP 8+ object-relational modeling with PDO prepared statements, client-side reactivity via Bootstrap 5.3 and Vanilla JavaScript, and an educational simulated financial gateway that eliminates sensitive financial vulnerability exposure. Automated test suites verify 100% of core transaction, security, and schema invariants, presenting a production-ready, academically rigorous benchmark for modern full-stack web applications.
