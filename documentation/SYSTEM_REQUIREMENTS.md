# SYSTEM REQUIREMENTS SPECIFICATION (SRS)
**Project Title:** MultiMart: All-in-One Multi-Model E-Commerce Marketplace  
**Document Code:** SRS-MM-2026-v1  
**Target:** B.Tech CSE / Data Science Major Project Evaluation  

---

## 1. Physical & Hardware Requirements

### Minimum Hardware Specifications (Local Execution)
- **Central Processing Unit (CPU):** 64-bit Dual-Core x86 or ARM64 processor @ 1.8 GHz or higher.
- **Random Access Memory (RAM):** Minimum 2 GB (4 GB recommended when hosting Apache + MySQL concurrently).
- **Secondary Storage:** 500 MB of persistent storage space for PHP scripts, SQLite/MySQL data directories, and uploaded graphics.
- **Display Resolution:** Minimum resolution of 1024 × 768 pixels (optimized for desktop, laptop, tablet, and mobile viewports).
- **Network Interface:** Standard loopback interface (`127.0.0.1` / `localhost`) for offline testing; standard TCP/IP networking if hosted over a LAN.

---

## 2. Platform & Hosting Environment
- **Operating Systems Supported:**
  - **macOS:** macOS Catalina 10.15 through macOS Sequoia 15+.
  - **Microsoft Windows:** Windows 10 / Windows 11 (64-bit).
  - **Linux Distributions:** Ubuntu 20.04/22.04 LTS, Debian 11/12, Fedora, RedHat Enterprise Linux.
- **Web Server Stacks:**
  - Standard XAMPP 8.0+ distribution (recommended).
  - Alternative: WAMP, MAMP, LAMP, or standalone PHP 8+ CLI built-in web server.
